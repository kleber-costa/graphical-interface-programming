# Graphical Interface Programming - UFF

This repository contains example applications developed as part of the exercises for the Graphical Interface Programming course in the Computer Systems undergraduate program at Universidade Federal Fluminense (UFF).

Each subdirectory in the repository corresponds to an independent Python project, with its own virtual environment and modules.

## Projects

- [Snake](snake/README.md) - A simple Snake game implemented in Python using Tkinter.
- [Tic Tac Toe](tic-tac-toe/README.md) - Simple Tic Tac Toe game implemented in Python using Tkinter.
- [Pong](pong/README.md) - A simple Pong game implemented in Python using Tkinter.

## How to use

1. Open the folder for the desired project.
2. Follow the instructions in the specific `README.md` for that project.

## Notes

- These projects are educational examples for the course and can be used as a reference to learn graphical interface concepts with Tkinter.
- If a project includes a local virtual environment, it should not be versioned. Dependency files should only be added when necessary.
